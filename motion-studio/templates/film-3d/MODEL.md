# <Product>: what the 3D model is based on

The model is built in code (`world.js` → `product()`) and path-traced (`pt.js`). Record here why each part looks the way it does. If the client or a reviewer asks "is that accurate?", this table is the answer.

| Feature | Source | Fidelity |
|---|---|---|
| Footprint W × D, module heights | official spec page (link) | exact |
| Front shell, corner radii | product photos (file names / URLs) | measured from images |
| Front print / LED indicator | product photos | measured; marks drawn as on the product |
| Back, ports, mounting bracket | not published / not needed | not shown |

## Illustrative choices (not instructions)
- **Stacking animation:** shows that the modules dock. Real installation follows the manufacturer's manual.
- **Energy lines:** a graphic overlay, not wiring.
